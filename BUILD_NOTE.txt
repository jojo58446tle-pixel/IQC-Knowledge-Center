IQC Knowledge Center V1 - ADP/JOJO API integration

Current integration:
Browser -> same-origin /api/chat -> Netlify Function -> Tencent Cloud ADP v2 Conversation API

ADP China SSE endpoint used by this build:
https://wss.lke.cloud.tencent.com/adp/v2/chat

Security:
- JOJO AppKey is NOT stored in frontend source.
- Configure JOJO_APP_KEY in Netlify Environment Variables.
- Rotate any AppKey that has previously been exposed in chat, screenshots, logs, or source.

Build verification:
Run npm install, npm run typecheck, npm run build before production deployment.

The old JOJO iframe is not the primary chat integration anymore.
